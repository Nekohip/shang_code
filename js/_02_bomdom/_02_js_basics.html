JavaScript 基礎入門

1. 變數 (Variables)

JavaScript 使用 let 和 const 來宣告變數。

  • let: 用於可以改變的值
  • const: 用於常數 (不可改變)
let name = "Shang"; const age = 25; // age = 26; // 這會報錯，因為 const 不能重新賦值

2. 函式 (Functions)

函式是一段可以重複使用的程式碼。

function sayHello(name) { return "你好, " + name + "!"; }

3. 互動 (DOM Manipulation)

JavaScript 可以改變網頁上的內容。

// 改變元素的文字 document.getElementById("demo").innerText = "文字被改變了！"; // 改變元素的樣式 document.getElementById("demo").style.color = "red";

點擊按鈕來改變這段文字的顏色！
